# MailCraft – Email Sending Web Application

MailCraft is a secure and responsive email sending web application built using Node.js and Nodemailer. The application allows users to send emails through a simple web interface using Gmail SMTP with App Password authentication.

---

## Features
- Send emails using Gmail SMTP
- Secure authentication using Google App Passwords
- Responsive and clean user interface
- Backend email handling using Nodemailer
- Error handling for failed email delivery
- Environment variable support for security

---

## Tech Stack
- Node.js
- Express.js
- Nodemailer
- Gmail SMTP
- HTML
- CSS
- JavaScript
