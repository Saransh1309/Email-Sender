## 📧 Mail Sender Application

A Node.js-based application designed to automate email sending using SMTP protocols. This project leverages Nodemailer to deliver emails efficiently with secure authentication and customizable HTML templates.

### 🚀 Features

* Automated email sending using SMTP
* Secure authentication via Gmail App Passwords
* Dynamic and reusable HTML email templates
* Environment variable management using `.env`
* Clean and modular code structure for scalability

### 🛠️ Tech Stack

* Node.js
* Nodemailer
* SMTP (Simple Mail Transfer Protocol)

### 🔐 Security

Sensitive credentials like email and passwords are managed using environment variables to ensure security and prevent exposure in version control.

### 📂 Use Cases

* Bulk email automation
* Notification systems
* Transactional email services

### ⚙️ Setup Instructions

1. Clone the repository
2. Install dependencies using `npm install`
3. Create a `.env` file and add your credentials
4. Run the application using `node app.js`

### 📌 Note

Make sure to enable App Passwords in your Gmail account for secure authentication.
